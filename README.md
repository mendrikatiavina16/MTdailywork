# MTdailywork
MT Suivi DTF est un tableau de bord et logiciel de gestion de production d'impression DTF. Il intègre une vue 3D interactive , un calendrier dynamique par jour, le suivi des métrages DTF (en cm/m et Ariary), la gestion des clients, des fiches de tâches avec extraction de fichiers, et un suivi des paiements.
